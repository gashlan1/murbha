واجهة المطوّرين العامة

المرجع المختصر لنقاط النهاية المتاحة للعامة على منصة مُرابحة. لا تحتاج مفتاح API للوصول لهذه المسارات — اطلب JSON مباشرة. للوصول إلى بيانات حساب محدّد ستحتاج إلى جلسة موقّعة (تسجيل دخول).

الاستخدام العادل: لا تتجاوز ٦٠ طلباً في الدقيقة لكل عنوان IP من مسارات /app/public/. للأحجام الأكبر، راسل api@murbha.sa.

المحتوى

GET /app/public/status GET /app/public/maintenance GET /app/public/platform-stats GET /app/public/ticker GET /app/public/activity GET /app/public/closing-soon GET /app/public/leaderboard GET /app/public/investor/:id GET /app/public/newsletter-issues GET /app/public/flags POST /app/feedback
GET/app/public/statusعام

حالة الخدمة

يعرض الحالة العامة للمنصة ومكوّناتها (API، قاعدة البيانات، البريد، الدفع، الرسائل).

{
  "overall": "operational",
  "components": [
    { "id": "api", "name": "API الأساسي", "status": "operational" },
    ...
  ],
  "metrics": { "projectsOpen": 4, "investmentsLast24h": 12, "userCount": 1240 },
  "serverTime": "2026-06-05T05:55:00.000Z"
}
GET/app/public/maintenanceعام

حالة الصيانة

يخبرك إن كان النظام تحت الصيانة الآن، مع رسالة ووقت متوقّع للعودة.

{ "active": false, "message": null, "eta": null, "scheduledStart": null, "scheduledEnd": null }

{ "investors": 312, "deals": 540, "completedProjects": 8, "openProjects": 4, "totalCapital": 41250000, "users": 1280 }
GET/app/public/tickerعام

شريط الاستثمارات

آخر الاستثمارات مجهولة الهوية، صالحة للعرض على شريط حي.

{ "ticker": [ { "investor": "محمد ع.", "amount": 5000, "project": "اسم المشروع", "at": "2026-06-04T..." } ] }
GET/app/public/activityعام

النشاط الحالي

يدمج الاستثمارات الجديدة، الصفقات المكتملة، وتوقيعات العقود مع إخفاء الأسماء.

{ "events": [ { "kind": "investment", "initial": "م", "title": "استثمار جديد", "detail": "...", "at": "..." } ] }
GET/app/public/closing-soon?days=14عام

{ "projects": [ { "slug": "...", "name": "...", "fundedPct": 67, "remainingMs": 1234567890, "closesAt": "..." } ], "days": 14 }

أرشيف النشرة

{ "issues": [ { "id": "nli_...", "slug": "...", "title": "...", "summary": "...", "publishedAt": "..." } ] }
GET/app/public/flagsعام

الأعلام (Feature flags)

قاموس key/value للأعلام التي فعّلتها الإدارة. مفيد لتطبيقات العميل التي تتفرّع على ميزات تجريبية.

{ "flags": { "darkmode_default": true, "new_calculator": false } }

إرسال ملاحظات

يُسجّل تعليق NPS اختياري المحتوى. الجلسة المسجّلة تُعبّأ تلقائياً بالاسم والبريد.

{ "score": 9, "category": "general", "comment": "تجربة ممتازة." }
