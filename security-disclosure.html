الإفصاح الأمني المسؤول

إن اكتشفت ثغرة أمنية في مُرابحة، ساعدنا في حماية مستثمرينا بإبلاغنا قبل الإفصاح العلني. نقدّر باحثي الأمن ونكافئ التقارير المؤثّرة.

كيف تُبلغ عن ثغرة

  1. أرسل تقريراً مفصّلاً إلى security@murabaha.example.sa.
  2. اشرح طبيعة الثغرة، خطوات إعادة الإنتاج، والتأثير المتوقّع.
  3. أرفق لقطات شاشة أو فيديو إن أمكن.
  4. سنردّ خلال ٤٨ ساعة، وسنوافيك بتحديثات منتظمة.
  5. لا تفصح علنياً قبل ٩٠ يوماً من الإصلاح أو موافقتنا.

النطاق

✓ نقبل التقارير عن

  • https://murabaha.example.sa والنطاقات الفرعية
  • تطبيق الجوال (PWA)
  • واجهات API العامة (/app/*)
  • إعدادات الأمان، المصادقة، التفويض
  • تسرّب البيانات أو خرق الخصوصية

✗ خارج النطاق

  • هندسة اجتماعية أو phishing
  • هجمات DoS أو brute force
  • ثغرات أنظمة الطرف الثالث (بدون تأثير)
  • تقارير من فحوصات تلقائية بدون تحليل
  • تقارير عن غياب headers أمنية بدون أثر
